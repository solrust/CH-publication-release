# Transcription factor perturbations

Analysis of pooled transcription factor overexpression in human hematopoietic stem and progenitor cells. In vivo barcode measurements describe clonal growth and lineage output; in vitro single-cell RNA-seq measures transcriptional responses to each perturbation.

## Data

Download **TF perturbation** and **RNA/LARRY** from the [dataset index](../publication/datasets.tsv). TF inputs include `TF_trends.RData`, `TF_invitro.RData`, `p2_tfinvitro.rds`, `TF_invitro_DE.RData`, `TF_consensus_signatures` and barcode-count tables. Comparisons with clonal phenotypes use `Association_analysis/data/processed/use/association_summary.RData` and the RNA gene sets.

The saved enrichment results in `publication/intermediate/TF_fgsea_pathways/` are supplied with the code and used by the pathway exporter.

## Run

Run from the repository root after completing the [environment setup](../publication/RELEASE_INSTALLATION.md).

```r
source("TF_overexpression/publication/run_publication.R")
run_tf_publication(
  panels = c("7C", "7D", "S12B"),
  output_root = file.path(getwd(), "TF_overexpression/publication/reproduction")
)
```

Use a new output directory. The same function supports the cell-assignment panels 7E, S12E and S13A–C, and the S12F marker-expression panel.

Additional analyses are available in the same script:

| Function | Figures |
| --- | --- |
| `tf_pathway_export()` | 7F, S13E–F |
| `tf_association_export()` | 7H–I |
| `tf_s13d_export()` | S13D |
| `tf_s13g_export()` | S13G |

## Outputs and scope

The functions write numerical tables to `source_data/` and PDFs to `figures/` beneath the selected output directory. They use processed inputs and saved model or enrichment results. The original processing and modelling scripts remain in `scripts/` and `R/`.

Fig. 7B/K and S13H are not generated by these workflows. The regenerated 7F heatmap may differ in row/column ordering, and the S13E representative-pathway selection does not exactly match the assembled panel. Pathway scores are signed −ln(P), not fold changes. These display differences do not change the exported enrichment statistics.
