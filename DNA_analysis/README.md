# Longitudinal DNA barcode tracing

Analysis of clone abundance and growth in the in vivo LARRY experiments. The publication workflow generates Fig. 2B–G and Supplementary Fig. 3J/K from longitudinal barcode measurements and saved growth-model results.

## Data

Download **DNA clonal tracking** and **RNA/LARRY** from the [dataset index](../publication/datasets.tsv). The principal inputs are:

```text
DNA_analysis/data/processed/DNA_clones.RData
RNA_analysis/data/processed/hashtag_meta.rds
```

The original processing script also uses RNA-based clone assignments and experiment-level barcode count tables. These are separate from the saved-results workflow below.

## Run

Run from the repository root after completing the [environment setup](../publication/RELEASE_INSTALLATION.md).

```r
source("DNA_analysis/publication/run_publication.R")
dna_pub_run(panels = c("2C", "S3J"), validate_replay = TRUE)
dna_pub_remaining(
  panels = c("2D", "2E", "2F", "2G", "S3K"),
  validate_replay = TRUE
)
dna_pub_fig2b()
```

Use a fresh checkout with the data restored; these functions refuse to replace existing outputs.

## Outputs

Numerical tables are written to `DNA_analysis/publication/source_data/` and figure components to `figures/`. Clone frequencies, growth estimates and model coefficients are read from `DNA_clones.RData`; the workflow does not refit the growth models or process FASTQs.

Figure 2A is a schematic. Fig. 2H and S3A–I are not generated by this project. The Fig. 2G plot does not recreate the additional significance annotation in the assembled artwork. Original barcode processing and growth modelling are retained in `scripts/`.
